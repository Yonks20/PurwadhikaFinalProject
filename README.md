# Term Deposit Campaign Intelligence

Streamlit dashboard built from `Bank_Term_Deposit_Prediction.ipynb` and `bank-additional-full.csv`.

## Run locally

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

The app provides campaign KPIs, filterable exploratory analysis, model-result reporting, and CSV export. It reports the validated notebook model results; it does not retrain or deploy a prediction model.
